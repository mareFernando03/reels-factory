# Base de conocimiento de la factory

Lo que hay que saber de Instagram, marca, contenido y publicidad para **decidir** un reel (al armar el guion) y **evaluarlo** (antes de entregarlo y después de publicarlo). La parte operativa es `rubrica.yaml`: los criterios que se aplican a cada reel. Los documentos explican el porqué de cada criterio.

Relevado el 02-03/10/2026. **Instagram cambia seguido:** revisar los puntos 🟢 cada seis meses o cuando haya un anuncio de Mosseri o de @creators.

## Niveles de evidencia

Cada afirmación lleva una marca. No es lo mismo lo que dice Instagram que lo que repite un blog:

| Marca | Qué significa | Cómo usarlo |
|---|---|---|
| 🟢 **Oficial** | Lo dice Instagram/Meta (about.instagram.com, creators.instagram.com, guías de anuncios de Meta, Adam Mosseri) | Regla. Si un reel lo incumple, se corrige |
| 🟡 **Medido** | Estudio de terceros con muestra declarada (Buffer, Socialinsider, Metricool) | Tendencia fuerte, no ley. Es correlación, no causa |
| ⚪ **Práctica** | Consenso de la industria, blogs o guías comerciales sin metodología | Punto de partida. Probarlo y medirlo con sus propios números |

Las cifras de blogs sin metodología ("el 65 % decide en 3 segundos", "50 millones de anuncios analizados") **no se usan** como argumento.

## Cómo la usa la factory

- **Al armar el guion** (paso 4): el guion tiene que poder justificar el gancho, el ritmo, los textos y el cierre con estos documentos.
- **En el control de calidad** (paso 5): se aplica `rubrica.yaml` y el resultado se escribe en `salida/evaluacion.md`. Si un criterio bloqueante falla, el reel no se entrega.
- **Después de publicar**: a las 72 h se comparan las métricas con `06-medicion.md` y se anota qué funcionó. Eso alimenta la elección de estilos.
